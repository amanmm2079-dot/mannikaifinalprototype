# Mannik AI

## Dynamic Distress Monitoring System

A web-based AI application designed to help monitor distress-related signals and provide appropriate support.

## Features

- User-friendly dashboard
- Distress monitoring
- AI-assisted analysis
- Responsive web interface
- Firebase integration
- Multi-language support

## Technology

- React
- TypeScript
- Vite
- Firebase
- Gemini API

## Project Structure

- `src/` – Application source code
- `src/components/` – UI components
- `src/services/` – Application services
- `src/firebase/` – Firebase configuration
